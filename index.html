Health Sync App Studio

This page serves as the configuration home for a private, personal background automation utility. This utility writes user-authorized fitness data to personal cloud metrics stores.

Privacy Policy

Effective Date: October 11, 2026

This application is exclusively built, maintained, and accessed by the developer for private, personal data logging use. It does not collect, monitor, store, or sell any consumer data to external servers or third-party groups.

Your Google Health API data is used strictly within the execution runtime environment of our automated cloud script to write data entries to your personal datastores. No data is stored persistently outside your private environment, and no information is shared with outside entities.
